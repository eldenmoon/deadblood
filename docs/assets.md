# 资产管理

运行资产统一位于 `dist/assets/`，避免多个文件夹保存同一版本。机器可读清单见 `assets-manifest.json`，包含尺寸、用途、运行时是否加载、体积和 SHA-256。

## v4 生成来源与意图

全部使用内置图像生成制作原创游戏素材，没有从原作攻略或商业游戏提取精灵。当前批次准确生成三张图集，没有额外重试。保留原始生成文件 不做覆盖式清理，裁剪/缩放由运行代码负责。

- NPC prompt brief：透明 RGBA、哥特像素风、4 列 3 行；红披肩灰裙人偶、轮椅老猎人、羽毛披风鸟面具双刃猎人；细微待机姿态，无文字或场景。实际尺寸 1536×1024。生成器没有完全遵守统一行距和脚底基线，因此使用单独边界。
- Equipment brief：透明 RGBA、DNF 感的清晰像素图标，5 列 4 行；锯刀/斧/杖/火锯/钟锤、镰/手枪/炮/双刃/枪矛、喇叭枪/喷火器/三衣装、三护符/红宝石/秘法书。实际尺寸 1402×1122。
- FX brief：透明 RGBA、4 列 4 行；金白红枪反冲击、青紫弧形斩、橙色地面火爆、蓝白冰晶新星。实际尺寸 1254×1254。少量顶峰帧接近分格边缘，运行时内缩取样。

此前六个 PNG 的完整生成提示没有作为原始文件保留；这里不虚构它们的提示。所有新资产必须补充生成来源、构图约定、尺寸、使用位置及实际查看结果。不要把生成的完整图集直接当作人物单帧，也不要依靠模糊滤镜掩盖边界。
