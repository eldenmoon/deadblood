# 资产管理

运行资产统一位于 `dist/assets/`，避免多个文件夹保存同一版本。机器可读清单见 `assets-manifest.json`，包含尺寸、用途、运行时是否加载、体积和 SHA-256。

## 向正式 Demo 过渡时如何保留

保留现有原型代码及全部 9 个 WebP：它们仍被运行代码引用，删除会破坏原型。当前它们是运行图与参考，不代表已经达到正式 Demo 美术标准。

| 资产类型 | 处理方式 |
| --- | --- |
| 背景、NPC 与敌人图集 | 在原型中保留；新场景/角色只参考其中合适的色彩与气氛，按统一制作规格重新验收 |
| 装备/技能图标 | 可以作为 UI 候选，检查风格及使用权；不能直接作为手持武器 |
| 枪反/刀光/火焰/冰晶 | 可作为效果时序参考或候选素材，需匹配动作轨迹并重新验收 |
| 新角色/动作制作源 | 开始 D0 时保留 `.blend`、绑定、动作、固定渲染设置、无损帧和锚点数据 |

当前 GitHub 主干包含压缩后的 WebP，没有 `.blend`、`.aseprite` 或可编辑骨骼资产。先前生成的 PNG 可在旧制作 checkout 的历史中找到，但没有随当前 GitHub 主干一起提供；克隆 GitHub 不会自动得到那些原始 PNG。不要把压缩图集称作完整制作源。后续收集母版时补齐出处和归档位置，不虚构原始提示词或文件。

## v4 生成来源与意图

全部使用内置图像生成制作项目图像，没有从原作攻略或商业游戏提取精灵。v4 批次生成三张图集。当前 GitHub 保存的是转换后的 WebP，原始文件的可用范围见上文；裁剪/缩放由运行代码负责。

- NPC prompt brief：透明 RGBA、哥特像素风、4 列 3 行；红披肩灰裙人偶、轮椅老猎人、羽毛披风鸟面具双刃猎人；细微待机姿态，无文字或场景。实际尺寸 1536×1024。生成器没有完全遵守统一行距和脚底基线，因此使用单独边界。
- Equipment brief：透明 RGBA、DNF 感的清晰像素图标，5 列 4 行；锯刀/斧/杖/火锯/钟锤、镰/手枪/炮/双刃/枪矛、喇叭枪/喷火器/三衣装、三护符/红宝石/秘法书。实际尺寸 1402×1122。
- FX brief：透明 RGBA、4 列 4 行；金白红枪反冲击、青紫弧形斩、橙色地面火爆、蓝白冰晶新星。实际尺寸 1254×1254。少量顶峰帧接近分格边缘，运行时内缩取样。

此前六个 PNG 的完整生成提示没有作为原始文件保留；这里不虚构它们的提示。所有新资产必须补充生成来源、构图约定、尺寸、使用位置及实际查看结果。不要把生成的完整图集直接当作人物单帧，也不要依靠模糊滤镜掩盖边界。

## 许可与保留文件

Three.js 旧模块未被现行入口引用，已从当前运行目录移除未引用的旧 Three.js 模块；历史内部版本仍保留第三方归属信息。资产参考与人物故事来源不等于可转授原作的知识产权；本仓库不附加对 Bloodborne、Dead Cells 或 DNF 商标和原作素材的授权。项目代码及新生成图像暂未声明开源许可，GitHub 仓库当前为公开。后续决定采用许可时应分别处理项目代码、生成图像与第三方运行库。
