# 需求与验收账本

基线：v4 / 2026-09-07。来源为本轮用户的八项反馈。下表中的“实现”代表功能已接入、已完成相应验证，不代表已经达到商业原作的完整制作水准。主观手感与难度仍需用户实玩确认。

| ID | 用户需求 | 本轮实现 | 验证与剩余事项 |
| --- | --- | --- | --- |
| R01 | 枪反有冲击感 | 独立枪反/处决事件、停顿、金白与红色火星、冲击图层、镜头与声音 | 浏览器枪反→处决；视觉检查。后续补全专用身体处决动画 |
| R02 | NPC 不要贴图感、模糊 | 人偶、老猎人、乌鸦猎人透明图集；独立基线；整数比例像素画布 | NPC 边缘检查。仍为离散帧，整体角色动画不是最终美术规格 |
| R03 | 场景字体清晰 | 场景文字移至原生分辨率 DOM，取消低分辨率画布字体 | 桌面高窗与阁楼标签检查；手机面板检查 |
| R04 | 装备背包技能 UI 与 AoE 更精致 | 像素图标格、品质边框、装备位和详情、配方卡、四技能两槽；多层火焰/冰晶/刀光 | UI 点击与技能选择验证；压低 AoE 高度避免过度遮挡 |
| R05 | 更多枪炮、双持、斧与稀有度 | 6 新武器，15 总定义；两个近战槽双持；5 品质；5 图纸合成 | 实际耗弹、范围伤害、副手命中、精力与扣料测试 |
| R06 | Boss 枪反 | 神父三阶段末段枪反；巨兽收招头部 3 次命中失衡 | 逻辑覆盖各阶段与巨兽；浏览器神父处决和提示 |
| R07 | 开场、探索故事、支线、隐藏 NPC/装备、通关后余韵 | 外乡抄书人血契开场；女孩/吉尔伯特/乌鸦猎人初段；胸针互斥选择；动态纪事、手记、自动/文件存档 | 分支、一次性奖励、回访、迁移、自动续玩验证。后期原作支线与教堂区尚未制作 |
| R08 | 太简单、怪少、地图单一、无攀爬 | 4 个亚南区域、36 敌人点；梯子与能力攀墙、屋顶回访、深坑、捷径；精力与补给约束 | 实际模拟移动上梯到阁楼；浏览器攀爬、旅行、回灯。仍待无辅助整章游玩平衡 |

## 已知限制

- 场景和身体动画仍有共用帧；处决没有完整专属骨骼动作。
- 关卡为固定布局；隐藏裂墙是一次性调查/奖励交互，尚无完整可破坏地形系统。
- 秘法雷葬与冰霜暂共用一组冰晶图集，机制与配色不同；后续需要独立雷电资产。
- 未复现原作全部敌人变种、支线失败条件或后期地图。
- 自动保存限当前浏览器，跨设备需导出导入。
- 全部地图总敌人点为 36；两位 Boss 包含在内，不另加。
