## 工作流

1. 新问题用 Bug 模板，补充地图、武器/升级、最后操作、截图与是否可重复；新需求用 Feature 模板。
2. 按影响排序：P0 数据损坏/无法继续；P1 战斗或任务关键功能错误；P2 视觉、提示和平衡；P3 新内容。
3. 分支 `fix/<issue>-short-name` 或 `feat/<issue>-short-name`，一个 PR 解决一个可验收目标。
4. 改机制补行为回归；改画面做截图/浏览器检查。涉及旧档先做迁移验证。
5. PR 写清玩家问题、变化、证据和限制。CI 通过后再评审。
6. 合并前更新 CHANGELOG 和需求状态；发布后保留可回退版本。
